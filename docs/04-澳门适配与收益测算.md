# 澳门适配与收益测算

本次新增场景仅在地域MO下执行M01—M06，导出地域配置与澳门输入；不执行R01—R15。一般上限两家及特别许可额外一家，依据第013/2025-AMCM号通告第3.2.2、4.1项。准照和委任输入待核实转人工，无效阻断；本地材料一致性与经办授权为机构策略示例。登记册及许可文件仍需人工或经授权系统核验。当前有效版本指业务发生时点的版本，不是今天的最新版本。

配置B为核查信息可用的合成分支；配置A假设缺少完整主事人清单。澳门证据保存年限独立核验，不沿用内地示例保存口径。

收益公式：H=N×(t0−t1)/60+A×(a0−a1)/60−Hm−Hr；V=H×W−O；首年=12V−I。所有参数为可替换假设。现金成本与工时成本不重复；核对和取证为不同任务；净工时不能直接视为现金利润。

测量建议：至少30个业务核对任务和10个取证任务作配对计时，交叉安排任务顺序；记录正确完成率、误阻断、人工介入。再连续观察四周替换模型参数，与现有系统扩展方案比较。程序回归与经济假设不能替代真实效果评估。
